HRN AI — version réponses rapides
- Les salutations simples (bonjour, salut, bonsoir, merci, etc.) reçoivent une réponse instantanée sans charger le modèle.
- Les demandes complexes utilisent toujours le modèle IA et peuvent être lentes, surtout au premier lancement sur 8 Go de RAM.
- Connexion Internet requise pour charger le modèle.
- Pour le site complet, ouvrir index.html ou suivre les instructions du dossier précédent.


Amélioration de compréhension des fautes de frappe
- Le prompt demande au modèle de comprendre les fautes de frappe, accents manquants et abréviations.
- Il demande une clarification courte si le sens reste réellement ambigu.
- Cette amélioration dépend du modèle d’IA utilisé et ne garantit pas la compréhension de toutes les phrases.


Fonctions image ajoutées : onglet Images pour générer une image via un service externe (connexion Internet requise) et sélection d’images jointes dans le chat avec aperçu. Le modèle de texte actuel ne comprend pas le contenu des images ; l’analyse visuelle par IA nécessite un modèle vision séparé.


VERSION RAPIDE : cette version limite la longueur des réponses pour accélérer la génération. Le premier chargement du modèle nécessite toujours Internet et peut prendre du temps. Après chargement, les réponses courtes sont généralement plus rapides.
\n\nFonctions images : les demandes de génération d’image sont affichées directement dans le chat via un service en ligne (Internet requis). Les photos jointes sont affichées dans la conversation, mais leur analyse par l’IA n’est pas encore activée : il faut connecter un modèle multimodal/vision.\n
